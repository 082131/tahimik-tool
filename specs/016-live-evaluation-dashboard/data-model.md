# Data Model: Live Evaluation Dashboard

## EvaluationExample

| Field | Type | Rules |
|---|---|---|
| `input` | string | non-empty, maximum 2,048 characters |
| `reference` | string | non-empty, maximum 2,048 characters |

## ModelTelemetry

| Field | Type | Meaning |
|---|---|---|
| `compression_mode` | `none\|fixed\|adaptive` | model deletion behavior |
| `input_byte_count` | integer | UTF-8 bytes before compression |
| `retained_byte_count` | integer | bytes passed to later encoder layers |
| `deleted_byte_count` | integer | removed bytes |
| `deletion_rate` | number | deleted/input fraction |
| `retained_byte_positions` | integer array | original retained byte indices; empty for ByT5 |
| `deleted_byte_positions` | integer array | original removed byte indices; empty for ByT5 |
| `noise_score` | number/null | TAHIMIK observed estimate only |
| `target_deletion_rate` | number/null | TAHIMIK target only |

## EvaluationJob

| Field | Type | Rules |
|---|---|---|
| `job_id` | UUID string | generated by backend |
| `status` | `queued\|running\|completed\|failed` | terminal states are completed/failed |
| `stage` | `validation\|accuracy\|profiling\|statistics\|complete\|failed` | current stage |
| `total_examples` | integer | 1–2,000 |
| `completed_examples` | integer | 0 through total examples |
| `created_at` | ISO-8601 string | persisted |
| `completed_at` | ISO-8601 string/null | persisted |
| `result` | EvaluationResult/null | present only when completed |
| `error` | string/null | safe message when failed |

## EvaluationResult

Contains `examples`, per-model aggregate `metrics`, per-model `efficiency`, and
two-pair `statistics`. CPU profiles mark memory unavailable instead of storing
zero as a measured value.
