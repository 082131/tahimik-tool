# Agent documentation

This folder contains the durable guidance that AI assistants must read before
working in this repository.

Read in this order:

1. [workflow.md](workflow.md) for the mandatory project rules and reading
   order.
2. [contributing.md](contributing.md) for branches, commits, review, and
   tests.
3. [handoff.md](handoff.md) when continuing documentation or defense-prep
   work.

The root [CLAUDE.md](../../CLAUDE.md) is intentionally only a discovery
pointer for tools that automatically load it.
